# Лабораторная работа №3: Интернет-магазин (Микросервисная архитектура)

Проект представляет собой веб-приложение для управления каталогом товаров интернет-магазина. Реализован полноценный CRUD-интерфейс с использованием микросервисного подхода: бэкенд на FastAPI (REST API + SQLite) и фронтенд на Flask с рендерингом HTML-шаблонов.

###  Технологический стек
| Компонент           | Технология                          | Назначение                                      |
|---------------------|-------------------------------------|-------------------------------------------------|
| **Бэкенд (API)** | Python, FastAPI, Pydantic           | Обработка запросов, бизнес-логика, маршрутизация|
| **База данных** | SQLite3 (raw SQL)                   | Хранение данных (файл `shop.db`)                |
| **Фронтенд** | Python, Flask, Jinja2, `requests`   | Рендеринг интерфейса и связь с API              |
| **Стилизация** | Bootstrap 5.3                       | Адаптивный дизайн, сетки, компоненты            |
| **Документация API**| Swagger UI (встроено в FastAPI)     | Интерактивное тестирование API                  |
| **Контроль версий** | Git, GitHub                         | Управление исходным кодом                       |

###  Основной функционал
- **CRUD операции:** Добавление, просмотр, редактирование и удаление товаров.
- **Продвинутый UI:** Карусель изображений для товаров, бейджи со скидками.
- **Массовые действия:** Возможность выделения нескольких товаров и их массового удаления.
- **Умные скидки:** Автоматический расчет финальной цены при указании процента скидки.
- **Смена темы:** Поддержка светлой и темной темы интерфейса (реализовано через HTTP cookies без JS).
